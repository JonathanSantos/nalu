# History

Design-time material from before v1, kept for the record and not updated since. It is in Portuguese and describes the language as it was then (for example, `or` instead of `catch` and `str[]` instead of `[]str`). For the language as it is, see [the documentation](../README.md).

- [specs/](specs/README.md): the specifications the compiler was first built from (frontend, Bash and PowerShell backends, CLI and tests, integration).
- [prompts/orquestrador.md](prompts/orquestrador.md): the prompt that coordinated that first build.
- [vs-stela.md](vs-stela.md): the comparison with Stela, the sibling language Nalu was chosen over.
